# Astra UI prototype

A standalone, disposable visual study for ejuicr. Uses the existing Dracula-inspired palette with a spacious workspace layout, illustrated recipe shelf, and static mixing-desk preview.

## Preview

Open `index.html` directly, or run from the repository root:

```sh
python3 -m http.server 4173 --directory prototype-astra
```

Visit http://localhost:4173. Stop the server with Ctrl+C.

All content and values are illustrative. Navigation jumps to page sections; there is no calculator, persistence, authentication, or CRUD. No JavaScript, build step, or dependencies. Google Fonts supplies DM Sans and Manrope when online, with local sans-serif fallbacks. All illustrations are CSS.
